# 西汽闲市境外网页试运行

本项目可先部署在中国香港或其他境外服务器，提供 HTTPS 网页。域名注册地或后缀不能单独决定大陆网站 ICP 备案要求；是否需要备案需按实际接入地及发布形态判断。小程序发布属于另一项流程，不由本网页模板覆盖。

## 已准备的配置

- `deploy/compose.production.yml`：MySQL、Node 应用和 Caddy，数据库及 Node 不映射到公网。
- `deploy/Caddyfile`：使用 `SITE_DOMAIN` 对外提供 HTTPS，并将 REST 与 Socket.IO 一并反向代理到应用。
- `deploy/.env.production.example`：所需变量示例。项目根目录的 `.env.production` 已被 Git 和 Docker 构建忽略。
- 生产容器强制 `NODE_ENV=production`、`DEMO_MODE=false`、`APP_ORIGIN=https://实际域名`，应用 Cookie 使用 Secure。

## 取得外部资源后按顺序执行

1. 确定平台运营主体，取得可用域名及服务器。域名 DNS A/AAAA 记录指向服务器；放通 80、443 端口以便 Caddy 申请证书。先核验大陆手机网络访问质量。
2. 将 `deploy/.env.production.example` 复制到项目根目录 `.env.production`，填写实际域名和分别生成的数据库、Session 强随机密钥。不要将这些值提交仓库或粘贴到聊天记录。
3. 开通短信服务并完成签名、模板审核。当前应用仅调用自定义 HTTP 网关 `SMS_GATEWAY_URL`，云厂商密钥不能直接填入 `SMS_GATEWAY_TOKEN` 代替网关适配。真实短信发送未打通前，正式模式的注册和找回密码会拒绝请求。
4. 准备隐私规则、用户协议、违禁商品和投诉申诉流程，落实运营人员。用新数据库启动服务，创建管理员，验证注册、审核、聊天、订单、争议和封禁流程。
5. 配置定期数据库与图片备份、异地保存、恢复演练、运行告警和升级回滚。先限定邀请用户试运行，再扩大访问。

示例命令（仅在真实环境准备齐全后执行）：

```bash
docker compose --env-file .env.production -f deploy/compose.production.yml up -d --build
curl https://实际域名/health
```

这里的“实际域名”需换成自己的域名。不要将公开 `docker compose config` 的输出用于求助，因为其中可能含有密钥。当前仅制作了部署模板，没有取得域名、服务器或真实短信资质，也未完成 Docker、公网证书、备份恢复及容量验收，因此此文档不代表可直接向公众开放。
