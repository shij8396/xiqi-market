Oracle 的 A1 每月免费额度为 1,500 OCPU 小时及 9,000 GB 小时，官方按持续运行约 2 OCPU、12 GB 内存说明；启动盘计入 200 GB 免费块存储总额。免费资源仅能在账户的 **home region** 使用。Oracle 当前区域列表中有新加坡 `ap-singapore-1`、`ap-singapore-2`，未列出香港。注册时如选新加坡，先在控制台确认目标区域和 A1 免费形状可用，home region 选定后不能因为缺货就直接将免费配额挪到其他区域。Oracle 可能回收连续七天低负载的免费实例。

Oracle 大多数新账户注册需要邮箱、手机号和银行卡核验；由账户所有人在 Oracle 官网自行填写，项目中不保存这些资料，也不要发给协助部署的人。免费试用与 Always Free 是两类额度；不要创建收费形状、额外收费磁盘或升级按量付费。免费的 Duck DNS 是平台子域名，不是可独立持有的品牌域名；正式运营、品牌迁移时应换为自己注册的域名。无银行卡时不要假定存在能长期免费运行本项目三容器的同等服务器。

如暂时不使用银行卡，可以用 Cloudflare Quick Tunnel 给本机生成临时 HTTPS 地址做少量邀请测试，但它依赖本机持续开机、地址随机且官方不保证可用性，不能当作正式服务器。Render 免费 Web 服务不提供持久磁盘，也无法直接承载本项目的本地 MySQL 和图片卷。

## 账号准备后执行

1. 用运营者长期控制的邮箱分别注册 Oracle Cloud 和 Duck DNS。Oracle 注册时选择合适的境外 home region；银行卡和验证码仅在其官网输入。若无法注册或 A1 长期缺货，再比较明确计费的境外 VPS，不自动启用收费服务。
2. 在 Oracle 控制台只创建一台标记为 Always Free eligible 的 Ubuntu Arm A1 实例，合计不超过 2 OCPU、12 GB 内存。使用默认 50 GB 启动盘。保存 SSH 私钥到运营者设备，不上传到项目、聊天或公开网盘。
3. 给实例分配公网 IPv4。云端安全规则放行 TCP 80、443；SSH 的 TCP 22 仅允许运营者当前公网 IP。系统防火墙也需允许同样端口。不要开放 MySQL 3306 或 Node 3088。
4. 在 Duck DNS 账号创建确认可用的 `名称.duckdns.org`，把 IPv4 指向实例公网 IP。确认 DNS 生效后，将该完整名称填入项目根目录 `.env.production` 的 `SITE_DOMAIN`。
5. 在服务器安装 Docker Engine 和 Compose 插件，上传本项目源码（不含 `.env`、`.env.production`、`.runtime`、`node_modules`、`uploads` 和本地演示数据库）。按 `deploy/.env.production.example` 建立服务器专用的 `.env.production`，为数据库和 Session 分别生成强随机密钥，并将文件权限设为仅运营账号可读。
6. 在项目根目录执行 `docker compose --env-file .env.production -f deploy/compose.production.yml up -d --build`。检查容器健康状态、`https://名称.duckdns.org/health`、浏览器证书和 WebSocket。现有部署配置强制 `DEMO_MODE=false`，不会创建演示账号或演示商品。
7. 使用 `scripts/create-admin.js` 建立管理员。真实短信网关、短信签名/模板及运营规则未准备好前，正式模式的手机号注册无法使用；不要把本地演示短信码功能开到公网。
8. 上线试运行前，备份 MySQL 和图片卷到实例之外，实际演练一次恢复；再逐项验证注册、登录、审核、收藏、议价、下单、聊天、投诉、订单争议和封禁。观察资源账单/免费配额以及大陆手机网络访问质量。

## 当前缺口

- 需要账号所有人完成 Oracle 与 Duck DNS 的登录/验证，才能真正申请实例和子域名；本站目前没有公网 IP 或域名。
- Docker Desktop 当前未启动，尚未完成本机容器构建与 Arm 目标环境验证。项目的自动化测试和前端构建不能替代公网部署验收。
- 真实短信网关尚未接入；真实用户注册、找回密码无法闭环。微信登录也需另行申请相应平台资质。
- 面向大众的交易平台还需要用户协议、隐私政策、禁售规则、举报/申诉处理、数据备份和运营责任人。是否需要备案需按实际服务器所在地与发布形态判断，不能靠“国外后缀”规避。
