# 西汽闲市大众版技术方案（同城面交阶段）

## 定位与边界

首期面向大众，先在西安同城试运行。一件商品对应一件实物，买卖双方在线沟通、议价、下单，在线下公共场所面交并当面付款。平台不代收款、无物流履约，不应被描述为已支持全国邮寄或担保交易。

## 用户与访问

- `USER`：手机号验证码注册，手机号与密码登录，可发布、收藏、聊天、议价、下单。找回密码通过已绑定手机号，成功后撤销原会话。
- `STUDENT`：兼容旧校园账号及历史订单，原有认证有效期继续生效；新用户注册页面无需学号。旧管理员名册接口保留供历史兼容，不是大众注册前置条件。
- `ADMIN`：审核商品、处理举报和争议、限制账号、查看审计日志。普通用户不能进入后台。
- `GUEST`：不落库的访客身份，仅浏览公开商品、图片、分类和面交区域。收藏、发布、聊天和订单均须登录。

`users.login` 对新用户存手机号，`users.phone` 同步存手机号，`verified_until` 对大众用户为空；旧校园账号保留学号登录与认证截止日。账号状态和角色由服务端校验，不能由客户端提交。需要把校园认证做成新用户可申请的可选标识时，应另设认证记录和审核流程，不应把 `USER` 改回 `STUDENT`。

## 商品与订单

新库初始化西安市雁塔、长安、碑林、未央、莲湖等公共面交区域。卖家在发布时选择所在区域；买卖双方在下单和改约时协商具体日期、时间及地点。这里的区域仍是固定列表，并非 GPS 地址或全国城市库。交易状态、商品独占预留、报价与订单幂等规则沿用原实现。邮寄模式需要单独的履约类型、地址保护、物流、签收、退款与争议状态，不能把当前面交字段简单改名。

## 部署

前端使用同源 `/api` 和 Socket.IO。境外试运行模板为 Caddy HTTPS → Express → 私有 MySQL；数据库和应用端口不映射公网。见 [境外网页试运行](境外网页试运行.md)。正式模式关闭演示验证码，需要真实短信网关。微信网页登录需要经过审核的网站应用参数；小程序需要独立前端与登录流程。

## 尚未完成的公众上线条件

真实短信适配与送达验收；运营主体、隐私规则、用户协议、账号注销及投诉渠道；卖家身份核验与违禁商品治理流程；数据库和图片备份恢复、监控告警、容量测试、Docker及公网 HTTPS 验收。完成前只能称为本机可用的同城面交原型，不能宣称公众生产环境已就绪。
